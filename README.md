# Malu — portfólio

Site estático: abra uma sessão HTTP com `python3 -m http.server 4387 --directory dist` nesta pasta. Acesse http://127.0.0.1:4387/.

- `dist/index.html`: textos de serviços e estrutura editáveis.
- `dist/content.js`: perfil de contato, fotografias e legendas da galeria.
- `dist/style.css`: cores, fontes, responsividade e composição.
- `dist/app.js`: GSAP/ScrollTrigger, menu e arraste.
- `dist/style-tile.html`: amostra de identidade usando os mesmos tokens.
- `dist/assets/logo-master.pdf`: master original fornecido, preservado.
- `docs/`: auditoria revisada, manifesto e direção criativa.

## Produção

Paleta oficial #CAD940 / #F29E44 / #E4DFC9. Assinatura PNG original. Anybody para títulos; Instrument Serif como substituição declarada de Silver Garden (arquivo/licença não fornecidos); DM Sans para leitura de interface. Gayathri referenciada no manual. Google Fonts requer conexão; há fallbacks locais.

As fotos foram separadas do mosaico incorporado em Portifólio.pdf, p. 6. Não houve geração de imagem nem vídeo; o movimento é de composição. São fotografias pessoais, não cases comerciais comprovados. Originais permanecem no download do usuário. Resolução individual aproximada: 435 × 550 px; fotos originais de alta resolução melhorariam as ampliações. Total de assets locais: 856,586 bytes.

Contato usa @amalucria, observado no branding, pendente de confirmação de atualidade. Não há telefone, email, formulário com envio ou métricas inventadas. A publicação hospedada ficou pendente: os scripts locais do plugin Sites ficaram indisponíveis durante a execução. A prévia local está funcional.

## Verificação realizada

Sintaxe JavaScript válida; referências locais de HTML verificadas. Abertura inspecionada em mobile e desktop, menu aberto/fechado e navegação por âncora exercitados no navegador. Scroll do desktop observado. Reduced motion implementado por media query, sem simulação automatizada nesta sessão.
